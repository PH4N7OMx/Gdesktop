# Жизненный цикл

Default export — функция `(api) => void | cleanup`, допускается async. Ready наступает после выполнения функции и её Promise. Cleanup может быть async, но имеет ограниченное время остановки.

При активации доступны settings/storage и регистрация интервалов. `api.settings` — readonly JSON-снимок; сохранение новых настроек перезапускает включённый экземпляр. Нет `onMessage`, произвольных таймеров и Node.js event loop.

Отключение, ошибка, обновление и удаление завершают экземпляр. Поздние ответы старого поколения не попадают в новый. Нельзя рассчитывать на новые API-вызовы из cleanup после остановки. Внешний watchdog завершает зависший host.

Нормальное закрытие клиента сохраняет включённую ревизию для следующего открытия. После аварии требуется ручное включение. Интервалы восстанавливаются без воспроизведения пропущенных событий.
