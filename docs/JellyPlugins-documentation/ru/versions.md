# Версии и совместимость

## API 1

JellyPlugins поддерживает TypeScript/JavaScript и пакеты `.jelly`. Старые `.jellyplugin` можно импортировать без переупаковки.

- События новых сообщений, отправка текста, HTTPS GET, хранилище, таймеры и кнопки.
- Отдельные права для вступления в каналы, callback-кнопок ботов, копирования вложений, редактирования исходящих сообщений, реакций и чтения истории.
- Просмотр установленного JavaScript в карточке плагина.
- Документация на русском и английском.

`apiVersion: 1` — версия контракта клиента, `version` — версия плагина. Дополнительные поля прав необязательны; старые пакеты не получают новые права автоматически. Обновлённый пакет требует повторного подтверждения.

API не совместим с Python-плагинами ExteraGram. TypeScript нужно упаковать SDK перед установкой.

Чтение и сохранение выбранных текстовых/двоичных файлов, баланс Stars/Telegram TON и главные Mini Apps имеют отдельные разрешения. Нужна версия клиента с этими API; старые клиенты отклоняют неизвестные разрешения.

См. [меню сообщений, диалоги и настройки](ui-and-settings.md): `menuChats`, `uiDialogs`, `settingsSchema` и пример Message Tools.
