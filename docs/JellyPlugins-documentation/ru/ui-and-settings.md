# Интерфейс и настройки

Штатная страница клиента показывает статус, режим, ожидание действий, следующий интервал, журнал, исходники, JSON-настройки, откат и удаление. Код открывается в широком окне моноширинным шрифтом.

Настройки — JSON-объект до 64 КиБ, доступный как `api.settings`. Сохранение перезапускает включённый экземпляр. Собственные окна, кнопки, toast, меню сообщений и декларативные формы через API пока не реализованы.

Окно разрешения строит клиент по проверенным параметрам. Описание автора не объясняет действие. Отправка показывает фактические аккаунт, чат/ID, полный текст и уведомление; история — чат и количество сообщений.
