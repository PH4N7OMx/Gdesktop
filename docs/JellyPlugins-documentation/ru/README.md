# JellyPlugins-documentation

Документация JellyPlugins для клиента GummyGram. API: **1**. Язык плагинов: **TypeScript или JavaScript**.

Плагины получают события клиента и выполняют действия через ограниченный API: отправляют сообщения и копируют вложения Telegram в выбранные чаты, обращаются к разрешённым HTTPS-сайтам, сохраняют собственные данные, работают по расписанию и добавляют кнопки на страницу JellyPlugins.

## С чего начать

- Пользователям: [установка и управление](installation.md).
- Разработчикам: [первый плагин](quickstart.md), [формат пакета](manifest.md), [справочник API](api.md).
- Перед выдачей доступа: [разрешения и безопасность](security.md).
- Для автоматизации: [примеры](examples.md), [ограничения и ошибки](errors.md).

## Платформы

В первой реализации исполнение плагинов доступно только на Windows с работающим AppContainer. На остальных системах пакет можно сохранить, но включение блокируется. Без изоляции код не запускается.

Пользователю не нужны Node.js, Python или npm. Node.js нужен разработчику для проверки TypeScript и упаковки исходников.

## Что доступно в API 1

| Возможность | Поддержка |
|---|---|
| Новые входящие сообщения в разрешённых чатах | Да, текст и основные идентификаторы |
| Отправка текста, ответ на сообщение, тихая отправка | Да |
| HTTPS GET в разрешённые домены | Да |
| Локальное JSON-хранилище плагина | Да |
| Повторяющиеся таймеры | Да, пока клиент открыт |
| Кнопки на странице плагинов | Да |
| Настройки экземпляра плагина | Да, JSON |
| Вступление в каналы, callback-кнопки ботов | Да, с отдельными разрешениями |
| Копирование вложений Telegram, редактирование своих сообщений, реакции, история | Да, с отдельными разрешениями |
| Произвольные хуки клиента, запуск системных программ | Нет |
| Каталог, подписи автора, автоматические обновления | Нет |

Возможности, которых нет в этой таблице или справочнике API, нельзя считать реализованными.
