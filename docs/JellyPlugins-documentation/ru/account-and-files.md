# Файлы, баланс и Mini Apps

Это отдельные API клиента, а не нативный FFI. Они не выдают DLL, произвольный доступ к файловой системе, ключи аккаунта или выполнение команд. Каждая возможность требует разрешения перед включением; новые флажки изначально сняты.

## Выбранные файлы

`files.readText()` требует `fileRead` и возвращает `{ name, text }`. `files.writeText(text, suggestedName = "export.txt")` требует `fileWrite` и возвращает `{ name }`. При каждом вызове клиент показывает окно выбора файла с названием плагина. Сохранение использует обычное подтверждение замены и атомарную запись. Отмена возвращает `USER_CANCELLED`.

Каждый файл ограничен 1 МиБ. Текстовые методы требуют корректный UTF-8. Полный путь не возвращается. Нельзя передать путь, получить доступ к каталогу или работать с файлами в фоне. Каталог `tdata` текущего клиента и символические ссылки запрещены. Пока пользователь выбирает файл, тайм-аут 30 секунд не действует. Выключение плагина закрывает окно выбора. После экранирования большой результат может превысить лимит JSON-кадра 2 МиБ: `RESPONSE_LIMIT`.

Предлагаемое имя — 1–120 символов без разделителей и запрещённых в Windows символов. Пользователь выбирает место и может заменить существующий файл. Это отдельная возможность: `sendAttachment` копирует вложения Telegram и не загружает локальные файлы.

Для двоичных файлов `files.readFile()` возвращает `{ name, base64 }`, а `files.writeFile(base64, suggestedName = "export.bin")` — `{ name }`. Разрешения и окно выбора те же. Base64 должен быть каноническим с padding; пустое содержимое допустимо. Лимит применяется к декодированным байтам.

## Баланс

`money.getBalance(currency = "stars")` требует `moneyRead`. Валюта: `"stars"` или `"ton"`. Результат `{ currency, whole: string, nanos: number }` приходит из Telegram для текущего аккаунта. Храни `whole` строкой, чтобы не потерять точность; `nanos` — миллиардные доли.

API читает Stars и собственный баланс TON в Telegram, если тот доступен. Он не подключается к стороннему приложению Wallet или произвольному TON-адресу. Недоступный баланс может вернуть ошибку Telegram. История операций, ключи, покупки, переводы и вывод средств не выдаются. Чтение баланса учитывается в общем лимите Telegram.

## Telegram Mini Apps

`miniApps.open(botId, { startParam? })` требует `webviewBots: ["123456789"]`. Укажи положительный ID бота, уже известного аккаунту. Поддерживается только главное Mini App бота. `startParam` — до 512 латинских букв, цифр, подчёркиваний или дефисов.

Открытие проходит через обычный механизм Telegram с подтверждением. Mini App получает стандартные данные профиля через Telegram. Плагин не получает initData, cookies, содержимое страницы, выполнение скриптов или управление платежами. `{ requested: true }` подтверждает только запрос открытия, а не загрузку, вход или оплату. После остановки плагина Mini App остаётся отдельным окном клиента.

Окна выбора файлов и открытия Mini Apps используют один слот взаимодействия на аккаунт и паузу минимум 30 секунд. Если окно выбора уже открыто, возвращается `INTERACTION_BUSY`. При частых запросах — `RATE_LIMIT` с `retryAfter`. Открытие Mini Apps также учитывается в общем лимите Telegram.

## Пример разрешений

```json
{"fileRead":true,"fileWrite":true,"moneyRead":true,"webviewBots":["123456789"],"ui":true}
```

Запрашивай только используемые возможности. Выбор файла лучше запускать явной кнопкой плагина, а не при активации. Совмещение чтения с HTTP или отправкой сообщений позволяет передавать содержимое файлов или баланс; объясни это в описании плагина.
