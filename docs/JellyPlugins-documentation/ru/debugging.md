# Отладка

Проверь новую версию клиента, API 2 и наличие штатного host. Сначала изучи статус и журнал: установка, активация и готовность различаются. Для диагностики доступны `api.log.info/error`.

Windows/Linux: `jelly-runtime` рядом с клиентом; macOS: `.app/Contents/Helpers`. Основной executable не копируется в AppData. Отсутствующий host исправляется полной установкой, а не отключением sandbox.

Проверь SDK через `npm run check` и `npm test`. Native результаты дают Actions `JellyPlugins v2 build and isolation` и испытания полного клиента. Не отправляй реальные сообщения автоматически ради теста и не записывай секреты/приватные чаты в журнал.
