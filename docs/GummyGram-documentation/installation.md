# Установка и управление

## Установить плагин

1. Открой настройки GummyGram → JellyPlugins.
2. Нажми «Установить JellyPlugin» и выбери файл `.jelly` размером до 1 МиБ.
3. Проверь имя, автора, описание и версию. Автор указан в пакете и пока не подтверждён подписью.
4. Подтверди сохранение пакета. Установка сама по себе не запускает код.
5. Открой карточку плагина → «Включить».
6. Разреши нужные чаты, сайты, хранилище, расписание и кнопки. Любой пункт можно снять.

Если Windows не позволяет создать изолированный процесс, плагин останется выключенным. Ошибку можно посмотреть в карточке.

## Настроить

В карточке открой «Настройки плагина» и введи JSON из инструкции автора. Настройки ограничены 8 КиБ; пароли и ключи аккаунта туда вводить не следует. Сохранение останавливает текущий процесс. Затем включи плагин повторно.

Пример для демонстрации RSS:

```json
{
  "url": "https://example.com/feed.xml",
  "chatId": "-1001234567890",
  "dryRun": true
}
```

Значения в настройках не расширяют разрешения. Если другой сайт или чат не указан в манифесте и не разрешён пользователем, запрос будет отклонён.

## Остановить

«Выключить и отозвать разрешения» завершает процесс, отменяет таймеры и незавершённые операции. «Остановить все плагины» делает это для текущего аккаунта. Другие аккаунты имеют отдельные экземпляры и разрешения.

Уже отправленное серверу сообщение или HTTP-запрос невозможно отменить задним числом. При остановке результат незавершённой отправки может быть неизвестен; не повторяй её автоматически без проверки.

После аварийного завершения клиента автозапуск плагинов блокируется. Включи нужный плагин вручную, проверив его статус и журнал.

## Удалить

В карточке выбери «Удалить плагин» и подтверди удаление пакета, настроек и сохранённых данных. История общего лимита отправок аккаунта сохраняется. Копия runtime и профиль AppContainer при этом автоматически не очищаются.

## Обновить

Установи новый пакет с тем же `id`. Предыдущий процесс остановится; разрешения потребуют нового подтверждения даже при неизменном манифесте. Настройки, хранилище и история лимита отправок сохраняются.

## Журнал и кнопки

В журнале отображаются последние 100 записей текущего запуска клиента. Журнал не сохраняется на диск. Автор плагина может сам записать туда текст сообщения, поэтому учитывай это при демонстрации экрана.

Кнопки, зарегистрированные плагином, появляются под его карточкой на странице JellyPlugins. Они доступны только при включённом плагине.

## Документация и код

Кнопка «Документация JellyPlugins» открывает русскую или английскую версию по языку клиента. В карточке «Посмотреть код» показывает установленный JavaScript с прокруткой и копированием. Просмотр не запускает код. Это результат упаковки; исходный TypeScript может выглядеть иначе.

Для изменения плагина редактируй исходники в SDK, снова упакуй и установи пакет. Встроенный редактор TypeScript пока не предоставляется.
