# Версии и изменения

## API 1 — предварительная реализация

Дата: 7 октября 2026 года.

- Пакеты `.jellyplugin`, TypeScript/JavaScript SDK и упаковщик.
- Работа плагинов в отдельных Windows AppContainer-процессах.
- Разрешения по чатам, доменам и отдельным возможностям.
- Новые входящие сообщения, отправка текста, HTTPS GET, JSON-хранилище, таймеры и кнопки.
- Управление из настроек, журнал, остановка и повторное подтверждение обновлений.
- Три примера и документация для импорта в GitBook.

Статус: исходная реализация, требующая сборки и испытаний в клиенте.

## Совместимость

`apiVersion` — версия контракта клиента. `version` — версия конкретного плагина. Сейчас принимается только `apiVersion: 1`. Неизвестная версия отклоняется, вместо попытки запустить несовместимый код.

Новое право не должно автоматически выдаваться существующему плагину. Новая версия пакета требует подтверждения пользователя даже при неизменных правах.

## Возможное развитие

Дальнейшие направления: декларативные формы настроек, вложения, редактирование и реакции, отдельные разрешения для действий с ботами и подписок, цифровые подписи автора, каталог, проверка обновлений, изоляция на Linux/macOS, дополнительные события и надёжные очереди.

Это направления развития; они не входят в текущий API. Совместимость с Python-плагинами ExteraGram отсутствует.
