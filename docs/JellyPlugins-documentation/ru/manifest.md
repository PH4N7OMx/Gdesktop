# Манифест и пакет

Плагин — JSON-файл `.jelly` с двумя полями: `manifest` и `code`. Формат не использует ZIP, поэтому в пакете нет путей файлов и установки вложенных исполняемых библиотек.

```json
{
  "manifest": {
    "apiVersion": 1,
    "id": "author.plugin-name",
    "name": "Название",
    "author": "Автор",
    "description": "Что делает плагин",
    "version": "1.0.0",
    "permissions": {
      "readChats": ["-1001234567890"],
      "sendChats": ["123456789"],
      "httpHosts": ["example.com"],
      "storage": true,
      "timers": true,
      "ui": true,
      "maxMessagesPerHour": 20
    }
  },
  "code": "var JellyPlugin = ..."
}
```

Создавай поле `code` упаковщиком SDK. Оно должно объявлять `JellyPlugin.default` — функцию активации. Имена полей API и манифеста чувствительны к регистру.

| Поле | Требование |
|---|---|
| `apiVersion` | Целое число `1` |
| `id` | 3–64 символа; начинается с латинской строчной буквы, дальше `a-z`, цифры, точка или дефис |
| `name` | Непустая строка до 80 символов |
| `author` | Необязательная строка до 80 символов; без подтверждённой подписи |
| `description` | Необязательная строка до 2000 символов |
| `version` | Три числовых компонента, например `1.2.0` |
| `permissions` | Обязательный объект; неизвестные разрешения отклоняются |

Чаты задаются **строками в формате Bot API**: положительное число для пользователя, отрицательное для группы, `-100…` для канала или супергруппы. Не преобразуй идентификаторы в JavaScript `number`.

`httpHosts` содержит только точные имена HTTPS-доменов без схемы, пути, порта и маски. `example.com` не разрешает `api.example.com`. Локальные адреса и частные сети блокируются дополнительно при выполнении запроса.

Любое поле разрешений можно опустить. Тогда доступ отсутствует. Лимит отправки по умолчанию — 20 операций Telegram в час; разрешён диапазон 1–60. В одном списке допускается до 32 чатов или доменов.

Хеш SHA-256 связывает подтверждение пользователя с конкретным пакетом. Это проверка целостности одобренной версии, а не подпись автора и не проверка на вредоносность.

## Дополнительные разрешения

| Поле | Доступ |
|---|---|
| `joinChannels` | Вступление в указанные каналы/супергруппы |
| `botChats` | Callback-кнопки ботов в указанных чатах |
| `attachmentChats` | Источники копируемых фото и документов |
| `editChats` | Редактирование исходящих сообщений |
| `reactionChats` | Изменение реакций |
| `historyChats` | Чтение старых сообщений |

Каждое поле — список до 32 ID чатов, например `"historyChats": ["-1001234567890"]`. Права не подразумевают друг друга. Копирование вложения дополнительно требует `sendChats` для получателя. `maxMessagesPerHour` сохраняет прежнее имя для совместимости и ограничивает все операции Telegram, а не только отправки.

| Новое разрешение | Доступ |
|---|---|
| `fileRead` | Чтение выбранного файла |
| `fileWrite` | Сохранение файла через выбор места |
| `moneyRead` | Чтение баланса Stars / Telegram TON |
| `webviewBots` | До 32 положительных ID ботов для Mini Apps |

Подробности: [файлы, баланс и Mini Apps](account-and-files.md).
