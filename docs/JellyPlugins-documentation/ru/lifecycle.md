# Жизненный цикл плагина

`TypeScript → упаковка → .jelly → установка → разрешения → активация → события`

## Активация

Установка сохраняет пакет. После включения клиент запускает изолированный процесс и вызывает функцию `export default` с `jelly` и `settings`. При каждой активации создавай обработчики, кнопки и таймеры заново. Ошибка активации останавливает плагин; ошибки обработчиков попадают в журнал.

События `message.new`, `timer` и `action` доставляются зарегистрированным обработчикам. Асинхронные вызовы могут пересекаться. `jelly.on(...)` возвращает функцию отписки.

## Где хранить данные

| Данные | После остановки / перезапуска | Назначение |
|---|---|---|
| Переменная в JavaScript | Теряется | Текущая очередь, флаг `busy` |
| `settings` | Сохраняется | JSON-настройки пользователя, отдельно по аккаунту и ID плагина |
| `storage` | Сохраняется | Счётчики, обработанные ID, состояние сценария |
| Таймеры, обработчики, кнопки | Регистрируются заново | Работа текущего экземпляра |
| Журнал | Не сохраняется на диск | Последние 100 записей в памяти клиента |
| Лимиты Telegram и FloodWait | Сохраняются | Ограничение операций после перезапуска и обновления |

Одинаковый ID на разных аккаунтах не означает общее хранилище или общие права. Настройки не расширяют разрешения из манифеста.

## Изменения и остановка

- Сохранение настроек останавливает плагин; включи его снова.
- Новый пакет с тем же ID заменяет код, сохраняет настройки и storage, требует нового подтверждения доступа.
- Выключение отзывает права и прекращает таймеры и текущие операции.
- Удаление очищает пакет, настройки и storage. Общий учёт лимита аккаунта сохраняется.
- После аварийного завершения клиента проверь статус и включи плагин вручную.

Не создавай повторную отправку автоматически при неизвестном результате. Сохрани контрольные ID и сверяй историю при необходимости. Данные сайтов и сообщений считай входными данными сценария.
