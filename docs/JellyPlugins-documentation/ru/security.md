# Разрешения и изоляция

| Режим | Поведение |
|---|---|
| Спрашивать | Каждая защищённая операция требует решения |
| Сохранённые правила | Совпадающее разрешение выполняется, незнакомое действие спрашивает |
| Полный доступ | Реализованный клиентский API без новых вопросов |
| Наследовать | Только для плагина: применяется глобальный режим |

Явный сохранённый запрет действует и в полном режиме. Разовое решение не создаёт правило. Можно запомнить точные нормализованные параметры. Для отправки есть явное разрешение разных текстов в одном чате с тем же `silent`. Другой чат или режим уведомления требует другого правила. Чтение истории разрешается отдельно. Правила привязаны к аккаунту, плагину, ревизии пакета и контракту API.

Запоминание разрешения в режиме «Спрашивать» переводит личный режим плагина на правила. Глобальный полный режим касается наследующих плагинов и будущих установок; это показано перед выбором. Личный режим переопределяет глобальный.

На экземпляр запускается отдельный host: AppContainer/Job Object на Windows, no_new_privs/seccomp на Linux, собственная App Sandbox-подпись на macOS. Fallback без изоляции отсутствует. Native испытания обязательны до выпуска; наличие кода sandbox не доказывает его надёжность.
