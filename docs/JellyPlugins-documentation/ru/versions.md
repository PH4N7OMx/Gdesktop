# Версии и совместимость

Версии пакета, API и IPC — 2. Старые пакеты/API 1 отклоняются. Нет миграции данных, разрешений или совместимого runtime.

Launcher, host и упаковка для Windows/Linux/macOS подключены в исходниках. Native/визуальные испытания реальных сборок ещё нужны. CI: Windows x64, Linux x64, macOS arm64/x64. Другие архитектуры и Store/Flatpak/AppImage этим не подтверждаются.

Смена контракта обесценивает прежний полный доступ и правила. Смена пакета требует включения новой ревизии, сбрасывает права и сохраняет один снимок для отката. Версия манифеста не заменяет SHA-256 содержимого.
