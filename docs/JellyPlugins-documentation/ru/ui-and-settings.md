# Меню сообщений, диалоги и настройки

## Действия над сообщением

Объяви `menuChats: ["123456789"]` и зарегистрируй `await jelly.ui.addMessageAction("inspect", "Просмотреть сообщение")` при активации. Клиент добавит пункт с названием плагина в меню одного серверного сообщения из этих чатов. Для служебных сообщений, выделения нескольких сообщений или части текста пункты плагинов не показываются. Дополнительные `ui` и `readChats` не нужны.

`jelly.on("message.action", ({ id, message }) => { ... })` вызывается только после нажатия пользователя. Сообщение содержит `chatId`, `messageId`, `senderId`, `text` (до 16384 символов), `date`, `outgoing` и `hasAttachment`. Внутренние объекты клиента и байты вложения не выдаются. Права и загруженное сообщение проверяются повторно при нажатии. Остановка или замена плагина делает пункты уже открытого меню недействительными. Если сообщение удалено или недоступно, событие не отправляется.

До восьми действий на плагин и шестнадцати на одно меню. ID — 1–64 символа; подпись — 1–80. Повторная регистрация заменяет подпись. `ui.removeMessageAction(id)` удаляет пункт. После активации регистрируй заново. `menuChats` разрешает чтение выбранных пользователем сообщений, а не фоновую подписку или историю. Отправка по-прежнему требует `sendChats`, HTTP — `httpHosts`. Опиши передачу данных в описании плагина.

`ui.removeAction(id)` удаляет кнопку, созданную через `ui.addAction`, и требует `ui`. Удаление отсутствующего ID считается успешным.

## Уведомления и подтверждения

Для этих методов нужно `uiDialogs: true`. Флажок разрешения изначально снят.

- `await jelly.ui.showToast(text)` возвращает `true` после запроса уведомления внутри клиента с названием плагина. Вход — 1–2000 символов; показываются первые 500. Уведомление Windows не создаётся. Для всех плагинов аккаунта действует пауза пять секунд.
- `await jelly.ui.confirm(title, text)` показывает текстовый диалог с названием плагина. Заголовок — 1–80 символов, текст — 1–2000. OK возвращает `true`; отмена, Escape или закрытие — `false`. Диалог не выдаёт новые разрешения API и не подтверждает платежи Telegram.

Диалоги используют общий слот и паузу 30 секунд вместе с выбором файлов и открытием Mini Apps. Если окно выбора или диалог плагина уже открыт, возвращается `INTERACTION_BUSY`. Во время ожидания пользователя обычный тайм-аут операции отключён. Выключение закрывает диалог и останавливает worker. Без окна аккаунта возвращается `UI_UNAVAILABLE_OR_INVALID_TEXT`; неверный заголовок даёт `INVALID_DIALOG_TITLE`. Автоматических повторов нет.

## Форма настроек

Необязательный массив `settingsSchema` в манифесте создаёт обычную форму вместо обязательного ручного JSON. Для настройки установленного плагина разрешение runtime UI не нужно. Подписи полей и вариантов задаёт автор, кнопки и пояснения клиента переводятся на язык клиента.

```json
"settingsSchema": [
  {"key":"enabled","label":"Включено","type":"boolean","default":true},
  {"key":"prefix","label":"Префикс","type":"string","default":"Просмотр","maxLength":40},
  {"key":"maxChars","label":"Максимум символов","type":"number","default":120,"min":1,"max":500},
  {"key":"mode","label":"Вывод","type":"select","default":"Просмотр","options":["Просмотр","Журнал"]}
]
```

До 16 полей и 4 КиБ компактного JSON UTF-8. У каждого поля обязательны уникальный `key`, непустой `label` (до 80 символов), `type` и подходящий `default`. Ключ — 1–64 ASCII-символа: сначала строчная буква, затем буквы, цифры, подчёркивания, точки или дефисы. Неизвестные свойства и типы отклоняются.

- `boolean` — переключатель.
- `string` — текстовое поле; `maxLength` по умолчанию 512, допустимо 1–2000.
- `number` — конечное число; стандартный диапазон от -1e9 до 1e9. Необязательные `min`/`max` должны быть конечными и внутри этих границ. Десятичный разделитель — точка.
- `select` — выбор одного значения: 1–8 уникальных непустых строк до 80 символов. Значение по умолчанию должно входить в список.

Пропущенные значения заполняются значениями по умолчанию. Настройки сохраняются для аккаунта и ID плагина; обновление их сохраняет. Несовместимое сохранённое значение нужно исправить перед запуском. Проверка действует и в форме, и в расширенном редакторе JSON. Неописанные JSON-ключи сохраняются; общий лимит настроек остаётся 8 КиБ. Сохранение останавливает плагин; включи его заново для получения новых настроек `settings`. Без схемы остаётся прежний редактор JSON.

## Попробовать

В SDK выполни `npm run pack:tools`. Перед упаковкой замени примерный ID в `menuChats`. Установи `examples/message-tools/dist/jelly.message-tools.jelly`, настрой форму и разреши меню/диалоги. Нажми правой кнопкой по сообщению в разрешённом чате и выбери `Message Tools · Inspect message`. Пример читает только выбранное сообщение и не выполняет отправок Telegram или HTTP-запросов.
