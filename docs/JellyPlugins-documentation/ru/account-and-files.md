# Доступ к аккаунту и файлам

Доступны отправка текста и чтение истории через проверенный Telegram bridge. Произвольные MTProto-вызовы, ключи сессии, экспорт аккаунта, баланс/платежи, Mini Apps, файлы, вложения и HTTP пока недоступны.

Полный режим разрешает реализованный клиентский API без повторного вопроса. Он не даёт прямой доступ к файлам, сети или командам ОС. Собственные JSON-данные сохраняются через `api.storage`.

Состояние и разрешения разделены по аккаунту и плагину. Автор и ID не удостоверяются центром доверия; просматривай код перед включением.
