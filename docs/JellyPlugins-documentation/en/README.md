# JellyPlugins v2

TypeScript/JavaScript plugins run in a separate QuickJS process. The new system is connected to GummyGram sources for Windows, Linux and macOS. Native builds and visual validation remain required; source edits do not update installed clients.

API 1 and old packages are rejected with no migration. Start with [your first plugin](quickstart.md), [permissions](security.md) and [API](api.md). These pages describe the implemented API 2 baseline.
