# Примеры

Оставлен нейтральный `jellyplugins/v2/examples/hello`: активация и строка журнала. Упаковка: `npm run pack:hello`. [Исходник и запуск](quickstart.md).

Тестовые сценарии перехватывают API-вызовы без реальных отправок Telegram. Native protocol/isolation tests используют отдельные fixtures. Успех JS-тестов не доказывает нативную изоляцию.
