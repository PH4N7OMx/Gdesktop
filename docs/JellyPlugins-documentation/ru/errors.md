# Ошибки и лимиты

Promise-ошибка содержит `code`, `message`, `stage`, при FloodWait — `retryAfter`. Обрабатывай отказ и сетевой сбой внутри async-handler.

| Код | Значение |
|---|---|
| `PERMISSION_DENIED` | Пользователь или правило запретили действие |
| `PERMISSION_REVOKED` | Права отозваны во время чтения |
| `REQUEST_EXPIRED` | Время ожидания истекло |
| `OUTCOME_UNKNOWN` | Отправка могла выполниться; не повторять автоматически |
| `CHAT_UNAVAILABLE` / `CHAT_NOT_WRITABLE` | Чат не загружен/недоступен либо требуется Stars |
| `FLOOD_WAIT` / `RATE_LIMIT` | Нужно учитывать задержку/лимит |
| `RATE_STATE_UNAVAILABLE` | Повреждено сохранённое состояние лимитов |
| `STORAGE_WRITE_FAILED` / `STATE_WRITE_FAILED` | Ошибка сохранения |
| `METHOD_UNAVAILABLE` / `INVALID_PARAMETER` | Неизвестный метод или параметры |

JS heap 64 МиБ, стек 512 КиБ, ход 250 мс, до 10000 microtasks за ход, 32 ожидающих запроса, 16 расписаний. Native-процесс ограничен отдельно. До 20 Telegram-операций в час на плагин и 60 на аккаунт; полный режим не снимает лимиты. API timeout 30 секунд, подтверждение 5 минут. Ошибки запуска/изоляции видны в статусе и журнале.
