# JellyPlugins v2

TypeScript/JavaScript-плагины исполняются отдельным QuickJS-процессом. Новая система подключена к исходникам GummyGram для Windows, Linux и macOS. Нативные сборки и визуальная проверка ещё нужны; установленный клиент от правки исходников не обновляется.

API 1 и старые пакеты отклоняются, миграции нет. Начни с [первого плагина](quickstart.md), [разрешений](security.md) и [API](api.md). Эти страницы описывают базовый набор API 2.
