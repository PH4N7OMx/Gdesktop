# Ошибки и лимиты

Методы API отклоняют `Promise` с ошибкой, содержащей `message`, `code` и `retryAfter` в секундах. `retryAfter` равен нулю, если время повторения не задано.

```typescript
import type { PluginError } from "../sdk-types";

try {
  await jelly.telegram.sendMessage(chatId, text);
} catch (cause) {
  const error = cause as PluginError;
  jelly.log(`${error.code}; повтор не раньше ${error.retryAfter} сек.`);
}
```

| Код | Значение |
|---|---|
| `PERMISSION_DENIED` | Метод, чат или домен не разрешён |
| `CHAT_UNAVAILABLE_OR_INVALID_MESSAGE` | Чат не загружен, нет права отправки, текст недопустим или сообщение платное |
| `INVALID_REPLY` | Некорректный ID сообщения для ответа |
| `RATE_LIMIT` | Исчерпан лимит отправок или не выдержана пауза |
| `FLOOD_WAIT` | Telegram потребовал паузу; учитывать `retryAfter` |
| `STATE_WRITE_FAILED` | Не удалось сохранить учёт попытки отправки; запрос не отправлен |
| `DNS_FAILED` | Не удалось разрешить имя сайта |
| `PRIVATE_NETWORK_BLOCKED` | DNS указывает на запрещённый адрес |
| `HTTP_RATE_LIMIT` | Слишком много HTTP-запросов |
| `HTTP_REDIRECT_BLOCKED` | Сайт ответил перенаправлением |
| `HTTP_BODY_LIMIT` | Ответ превысил допустимый объём |
| `HTTP_FAILED` | Сеть, TLS или HTTP завершились ошибкой |
| `INVALID_KEY` | Недопустимое имя ключа хранилища |
| `STORAGE_LIMIT` | Хранилище превысило 64 КиБ |
| `STORAGE_WRITE_FAILED` | Ошибка сохранения хранилища |
| `INVALID_TIMER` | Недопустимый период, имя или число таймеров |
| `INVALID_ACTION` | Недопустимая кнопка |
| `TOO_MANY_REQUESTS` | Одновременно ожидают более 32 запросов SDK |

Другие ошибки Telegram могут возвращаться как серверные коды, например `CHAT_WRITE_FORBIDDEN`.

## Ограничения

| Ресурс | Лимит |
|---|---|
| Установленные плагины | 16 на аккаунт |
| Пакет | 1 МиБ |
| Настройки | 8 КиБ |
| Хранилище | 64 КиБ |
| Рабочий процесс | 256 МиБ, один процесс |
| Непрерывное выполнение JS | 2 секунды на обработку кадра |
| Ожидание подтверждения worker | 5 секунд |
| Очередь событий | 64 кадра |
| Незавершённые запросы SDK | 32 |
| Незавершённая операция | 30 секунд; затем плагин останавливается |
| HTTP | 20 запросов в минуту, ответ 1 МиБ |
| Таймеры | 16, период 10–86400 секунд |
| Кнопки | 8 |
| Журнал | 100 записей по 500 символов |

Лимит сообщений считается по попыткам операций Telegram, а не только по успешным ответам. Попытки и FloodWait сохраняются на диск, поэтому обновление или перезапуск не должны обнулять их. Между операциями требуется минимум 3 секунды. Лимиты плагина не гарантируют, что Telegram разрешит такую частоту.

Дополнительно действует общий лимит 60 операций Telegram в час на аккаунт для всех плагинов. FloodWait одного плагина приостанавливает операции остальных плагинов этого аккаунта. Удаление плагина не обнуляет общий учёт.

Не используй `while (true)` для ожидания: регистрируй таймер. Не пытайся обойти лимит созданием нескольких плагинов. После сообщения с неизвестным исходом повтор может создать дубликат.

## Дополнительные ошибки Telegram

- `CHAT_UNAVAILABLE` — чат не известен сессии.
- `BUTTON_UNAVAILABLE` — сообщение/кнопка не загружены либо тип кнопки не поддерживается.
- `ATTACHMENT_UNAVAILABLE` — вложение не загружено, защищено или не подходит получателю.
- `MESSAGE_NOT_EDITABLE` — сообщение не загружено, не исходящее, срок редактирования истёк или текст недопустим.
- `INVALID_MESSAGE_ID`, `INVALID_CHANNEL`, `INVALID_HISTORY_OPTIONS`, `INVALID_REACTION` — неверные параметры.
- `INTERACTIVE_JOIN_REQUIRED` — вступление требует интерактивного сценария.
- `RESPONSE_LIMIT` — ответ истории не помещается в лимит кадра 2 МиБ; уменьши `limit`.

Другие коды ошибок Telegram передаются без изменения. Все вызовы Telegram расходуют лимит `maxMessagesPerHour`, включая чтение истории.

## Файлы и взаимодействие

| Код | Значение |
|---|---|
| `USER_CANCELLED` | Пользователь отменил выбор файла |
| `INTERACTION_BUSY` | Уже открыто окно выбора файла |
| `INVALID_FILE_CONTENT_OR_NAME` | Неверный тип, размер или имя файла |
| `FILE_UNAVAILABLE` | Запрещённый или недоступный путь |
| `FILE_UNAVAILABLE_OR_TOO_LARGE`, `FILE_NOT_UTF8_OR_TOO_LARGE` | Файл недоступен, превышает 1 МиБ или содержит неверный UTF-8 |
| `FILE_WRITE_FAILED` | Запись не завершена |
| `INVALID_CURRENCY` | Нужны stars или ton |
| `MINI_APP_UNAVAILABLE_OR_INVALID_PARAMETER` | Бот не загружен, нет главного Mini App, окна клиента или неверный startParam |

Для выбора файлов тайм-аут операции не действует. Открытие окна ограничено паузой 30 секунд на аккаунт; `RATE_LIMIT` содержит `retryAfter`.
