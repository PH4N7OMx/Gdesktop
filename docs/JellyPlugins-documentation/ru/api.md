# Справочник API 1

Функция по умолчанию получает `jelly` и `settings`. Настройки — JSON-объект, сохранённый пользователем для данного плагина и аккаунта.

```typescript
import type { Plugin } from "../sdk-types";

const activate: Plugin<{ destination: string }> = async (jelly, settings) => {
  jelly.log(`API ${jelly.apiVersion}`);
};

export default activate;
```

Все методы, возвращающие `Promise`, могут завершиться ошибкой. Разрешения проверяются в основном процессе клиента, даже если плагин подделает запрос в обход SDK.

## События

`jelly.on(event, handler)` возвращает функцию отписки. До 32 обработчиков каждого события.

### `message.new`

```typescript
jelly.on("message.new", message => {
  jelly.log(`${message.chatId}: ${message.text}`);
});
```

Поля: `chatId: string`, `messageId: number`, `senderId: string`, `text: string`, `date: number` — время Unix в секундах. Текст ограничен 16384 символами.

Только новые входящие несервисные сообщения с серверным ID, из разрешённых `readChats`. Исходящие сообщения плагинов и обычная загрузка старой истории не являются этим событием. Во время восстановления обновлений после офлайна клиент может получить накопившиеся входящие сообщения: при необходимости фильтруй по дате и сохраняй обработанные ID.

Событие не содержит медиа, номера телефона, полного профиля или ключей доступа.

### `timer`

Поля: `name: string`, `timestamp: number`. Возникает по зарегистрированному таймеру.

### `action`

Поле `id: string`. Возникает, когда пользователь нажал зарегистрированную кнопку на странице плагинов.

Асинхронные обработчики могут выполняться с пересечением. Используй флаг `busy` или последовательную очередь для операций с общим состоянием. Ошибки обработчика записываются в журнал; ошибка активации останавливает плагин.

## Telegram

```typescript
const result = await jelly.telegram.sendMessage("-1001234567890", "Текст", {
  replyTo: 123,
  silent: true
});
```

Нужен разрешённый `sendChats`. Текст 1–4096 символов, обычный текст без HTML/Markdown-форматирования. `replyTo` — положительный ID сообщения в том же чате. `silent` отключает звуковое уведомление отправки.

Возвращает `{ accepted: true, messageId: number }` после успешного ответа сервера. Если сервер не вернул соответствие ID, `messageId` равен `0`; не используй его как ID ответа. Серверное принятие не означает прочтение получателем.

Чат должен быть известен текущей сессии и доступен для отправки. Сообщения, требующие оплаты Stars, запрещены. Автоматического обхода лимитов или повторной отправки нет. Не повторяй запрос после обрыва с неизвестным результатом.

## HTTP

```typescript
const response = await jelly.http.get("https://example.com/feed.xml");
const text = response.text;
```

Нужен разрешённый домен `httpHosts`. Только HTTPS GET, порт 443. Возвращает `{ status: number, text: string }`. Ответ декодируется как UTF-8; бинарные файлы не поддерживаются.

Редиректы, URL с логином/паролем, частные IP и локальные сервисы запрещены. DNS-адрес проверяется и закрепляется для соединения; сертификат проверяется для исходного имени сайта. Cookies и авторизация браузера не передаются. Запросы идут напрямую, без использования прокси аккаунта Telegram.

Ограничения: до 20 запросов в минуту на плагин, ответ до 1 МиБ, сетевой тайм-аут 15 секунд. Нет метода POST, загрузки файлов или произвольных заголовков.

## Хранилище

```typescript
const count = await jelly.storage.get<number>("count") ?? 0;
await jelly.storage.set("count", count + 1);
await jelly.storage.remove("count");
```

Нужно `storage`. Значение — JSON; отсутствующий ключ возвращает `null`. `set` и `remove` возвращают `true`. Хранилище изолировано по аккаунту и ID плагина, сохраняется после перезапуска и обновления.

До 64 КиБ на весь объект; имя ключа 1–128 символов. Файлы хранилища не шифруются отдельно: не сохраняй пароли и секреты. Последовательность `get` → `set` не является транзакцией между параллельными обработчиками.

## Таймеры

```typescript
await jelly.timers.every("poll", 60);
jelly.on("timer", async ({ name }) => {
  if (name === "poll") jelly.log("Проверка");
});
await jelly.timers.cancel("poll");
```

Нужно `timers`. До 16 таймеров, имя 1–64 символа, период 10–86400 секунд. Повторная регистрация имени заменяет таймер. После перезапуска регистрируй таймеры заново в функции активации. Пропущенные тики не накапливаются; компьютер в режиме сна не выполняет работу.

## Интерфейс

```typescript
await jelly.ui.addAction("refresh", "Проверить сейчас");
jelly.on("action", ({ id }) => {
  if (id === "refresh") jelly.log("Проверяем");
});
```

Нужно `ui`. До 8 кнопок; ID 1–64 символа, заголовок 1–80 символов. Повторная регистрация ID обновляет заголовок. Кнопки находятся на странице плагинов, не в произвольных окнах клиента.

## Журнал

`jelly.log(text)` не требует разрешения. Текст до 500 символов; последние 100 записей хранятся в памяти. Не записывай секреты или полную переписку без необходимости.

## Дополнительные действия Telegram

Все чаты задаются строками в формате Bot API. Чат должен быть известен сессии. Вступление поддерживает известные каналы и супергруппы по ID; ссылки-приглашения, платные и интерактивные сценарии не поддерживаются.

| Метод | Разрешение | Результат |
|---|---|---|
| `joinChannel(chatId)` | `joinChannels` | `true` после ответа сервера |
| `getHistory(chatId, { beforeId?, limit? })` | `historyChats` | Массив сообщений от новых к старым |
| `clickButton(chatId, messageId, row, column)` | `botChats` | `{ text, alert }` |
| `sendAttachment(chatId, sourceChatId, messageId, { silent? })` | `attachmentChats` для источника и `sendChats` для получателя | `{ accepted, messageId }` |
| `editMessage(chatId, messageId, text)` | `editChats` | `true` |
| `setReaction(chatId, messageId, emoji)` | `reactionChats` | `true` |

`getHistory`: по умолчанию 20, от 1 до 100 сообщений. `beforeId` — исключительная верхняя граница ID, `0` означает последнюю историю. Поля сообщения: `chatId`, `messageId`, `senderId`, `text`, `date`, `hasAttachment` и `buttons: { row, column, text }[]`. Профили пользователей и содержимое файлов не выдаются. Загрузка истории не создаёт `message.new` и не отмечает сообщения прочитанными.

`clickButton` принимает индексы строки и столбца с нуля. Сообщение должно быть загружено: открой чат либо используй `getHistory` с дополнительным правом. Доступны обычные inline callback-кнопки; URL, покупки, пароль 2FA, WebView и запросы телефона/геолокации не выполняются. Ответ бота не открывает ссылки автоматически.

`sendAttachment` копирует фото или документ из загруженного сообщения Telegram вместе с подписью, без указания автора пересылки. Для загрузки источника можно открыть чат или вызвать `getHistory`. Защищённые от пересылки сообщения и платные отправки запрещены. Метод не загружает файлы с устройства или HTTP. Сервер проверяет ограничения получателя; `messageId` может быть `0`.

`editMessage` изменяет текст своего загруженного сообщения или подпись вложения: 1–4096 символов. Права и срок редактирования проверяет клиент и Telegram. `setReaction` заменяет реакцию обычным emoji; пустая строка снимает реакции. Платные и custom emoji не поддерживаются.

```typescript
const messages = await jelly.telegram.getHistory(chatId, { limit: 20 });
const message = messages.find(item => item.buttons.length);
if (message) {
  // Вызови действие позднее: не менее 3 секунд после getHistory.
  const button = message.buttons[0];
  await jelly.telegram.clickButton(chatId, message.messageId, button.row, button.column);
}
```

В примере нужны и `historyChats`, и `botChats`. Между запросами требуется пауза не меньше 3 секунд; обработай `RATE_LIMIT` и `retryAfter`. Все операции Telegram расходуют общий лимит аккаунта и лимит `maxMessagesPerHour` плагина, включая чтение истории.
