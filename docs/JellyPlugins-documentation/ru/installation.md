# Установка и управление

Установка `.jelly` проверяет и сохраняет пакет без исполнения. Просмотри код, затем включи плагин. Реальная защищённая операция запрашивает решение согласно режиму и правилам.

Доступ задаётся глобально или отдельно для плагина. Можно остановить все, отключить один, изменить JSON-настройки, удалить одно/все правила, открыть журнал и исходники.

Обновление пакета с тем же ID останавливает старый экземпляр, сбрасывает права и требует включения новой ревизии. Один предыдущий снимок кода/данных доступен для отката; откат тоже сбрасывает права. При удалении можно оставить настройки/storage. Права не сохраняются.

Расписания требуют открытого клиента. После аварии нужно ручное включение. Отсутствующий host или недоступный sandbox показываются как ошибка запуска; обхода изоляции нет.
