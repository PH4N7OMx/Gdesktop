# Interface and settings

The client page displays status, mode, pending actions, next interval, log, source, JSON settings, rollback and uninstall. Code opens in a wide monospace viewer.

Settings are a JSON object up to 64 KiB, exposed as `api.settings`. Saving restarts the enabled instance. Plugin-created windows, buttons, toast, message menus and declarative forms are unavailable in this baseline.

Approval dialogs are generated by the client from validated parameters, not author descriptions. Sending displays the actual account, recipient/ID, complete text and notification setting. History displays recipient and requested count.
